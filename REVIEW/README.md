# REVIEW/

This directory contains the review materials for AetherHuman.

## Phase 2 — Hypothesis Review

Phase 2 has **two components**:

1. **Internal review** — completed. The author reviews the author's own materials. This is threat T1 made concrete.
2. **Independent review** — not yet started. Requires an external reviewer who meets the independence criteria.

## Contents

| File | Purpose |
|---|---|
| `INTERNAL_REVIEW.md` | Internal review of the hypothesis, boundaries, falsification plan, and decision. |
| `INDEPENDENT_REVIEW.md` | Template for an independent reviewer (5 questions). |
| `INDEPENDENT_REVIEW_PROTOCOL.md` | Protocol for conducting the independent review (tracks A–D, outcomes A/R/F/D/E). |

## Status

| Component | Status |
|---|---|
| Internal review | ✅ Complete |
| Independent review | ⏳ Not started |
| Independent review protocol | ✅ Complete (ready to use) |

## How to use

1. The author sends the reviewer:
   - `ARCHITECTURAL_HYPOTHESIS.md`
   - `research/RESPONSIBILITY_BOUNDARIES.md`
   - `FALSIFICATION/FALSIFICATION_PLAN.md`
   - `DECISIONS/INDEPENDENCE_DECISION.md`
   - `REVIEW/INTERNAL_REVIEW.md`
   - `REVIEW/INDEPENDENT_REVIEW.md` (template)
   - `REVIEW/INDEPENDENT_REVIEW_PROTOCOL.md` (protocol)

2. The reviewer:
   - Declares independence.
   - Completes one or more tracks (A, B, C, D).
   - Issues an outcome (A / R / F / D / E).

3. The author:
   - Records the review in `INDEPENDENT_REVIEW.md`.
   - Updates `ROADMAP.md` (Phase 2 → ✅ Complete).
   - Updates `DECISIONS/INDEPENDENCE_DECISION.md` if the outcome changes.
   - Re-deploys the site.

## What this directory does not contain

- Implementation code.
- Test results.
- Experimental data.
- Claims that AetherHuman is independent.
