# paper/

This directory contains the original research paper for AetherHuman.

## File

- `AetherHuman_Research_Paper_v1.0.0.pdf` — 29 pages, ~11,000 words, 30 references. The original architectural investigation, as published with the v1.0.0 release.

## Versioning note

The paper is the **v1.0.0 artifact**. It has not been rewritten or reissued.

The **v2.0.0 release** (DOI: 10.5281/zenodo.24314201) is a methodological and documentary update, not a replacement of the paper. It adds:

- Phase 2 completion (Independent Review signed by Jonathan Rabe).
- The **Stronger Argument Memo for H-F2** (`research/STRONGER_ARGUMENT_MEMO_v3.0.0.md`).
- The **Evaluation Design** (`FALSIFICATION/EVALUATION_DESIGN.md`).
- The **Adversarial Threat Model** (`research/ADVERSARIAL_THREAT_MODEL.md`).

The scientific conclusions of the paper remain unchanged: the decision is **(E) Undetermined (interim)**.
