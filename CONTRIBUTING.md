# Contributing to AetherHuman

## Status

AetherHuman is **paused at Phase 4 (Independence Decision)**. The decision is **(E) Undetermined (interim)**. No implementation is planned unless the independence decision becomes positive.

## What contributions are welcome

At this phase, the following contributions are welcome:

1. **Independent review** of the hypothesis, the responsibility boundaries, and the falsification plan. This is Phase 2 and is the most valuable contribution.
2. **H-F2 analysis** — a function-by-function analysis to determine whether the remainder after composition with existing dimensions is non-trivial.
3. **H-F3 analysis** — an analysis of the adversarial-human case, not only the cooperative-human case.
4. **Citation corrections** — if you find a missing or incorrect reference.
5. **Typo fixes** and minor clarifications.

## What contributions are NOT accepted at this phase

1. Pull requests adding implementation code (`src/`, `tests/`, `experiments/`). Phase 5 and 6 are not permitted.
2. Specification proposals (`SPECIFICATION.md`). Requires a positive Phase 4.
3. Claims that AetherHuman is an independent dimension. The decision is (E); it is not (A).
4. Rewriting the hypothesis or the decision. These are the author's records and reflect the current state.

## How to contribute

1. Open an issue describing what you want to change and why.
2. Wait for a response. Not all issues will be accepted.
3. If accepted, submit a pull request against `main`.
4. Use clear commit messages. Reference the issue number.

## Code of conduct

Be respectful. This is a research project, not a software product. Disagreement is welcome; dismissal is not.
